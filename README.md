# Projeto 1 - Player de Música

App Android de música desenvolvido como projeto da disciplina **Desenvolvimento Móvel**.

O app busca músicas no **Deezer**, reproduz prévias de 30 segundos, busca letras pelo **lyrics.ovh** e permite criar playlists locais persistidas com **Room**.

## Pré-requisitos
- **Android Studio**

- Conexão com a internet (necessária para as APIs de busca e letras)
---

## Como executar

### Pelo Android Studio (recomendado)

1. Abra o Android Studio.
2. Vá em **File → Open** e selecione a pasta raiz do projeto (a pasta que contém `settings.gradle.kts` e `gradlew`).
3. Aguarde o sync do Gradle terminar.
4. Selecione um dispositivo:
   - **Emulador:** abra o **Device Manager** (canto direito da IDE), crie um device se ainda não tiver e dê start.
   - **Dispositivo físico:** conecte via USB com a **Depuração USB** ativada nas opções de desenvolvedor do Android.
5. Clique no botão **Run** (ou pressione `Shift + F10`).
6. Aguarde a instalação. O app abrirá automaticamente no dispositivo selecionado.


## Rodando os testes

### Pelo Android Studio

1. Clique com o botão direito na pasta `app/src/test/java/com/example/projeto1/`
2. Selecione **Run 'Tests in projeto1'**
